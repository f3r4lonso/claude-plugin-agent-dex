# agent-dex (API)

Local API and bundled web UI for Agent Dex, the Claude Code plugin that collects, creates and runs AI agents and skills.

```text
uvx --from "git+https://github.com/f3r4lonso/claude-plugin-agent-dex#subdirectory=api" agent-dex serve --open
```

See the [project README](https://github.com/f3r4lonso/claude-plugin-agent-dex) for details.
